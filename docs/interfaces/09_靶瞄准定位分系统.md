| 发次编号 | `shot_id` | DevLong | 发次唯一标识 | 正整数 |
| 阶段编号 | `phase_id` | DevShort | 发射三阶段编号 | 1/2/3 |

| 返回值 | Tango 类型 | 描述 |
|--------|-----------|------|
| 接收状态 | DevShort | 见状态码 |

| 值 | 含义 |
|---|---|
| 0 | 失败 / 异常 |
| 1 | 收到（已接受指令） |
| 2 | 无服务权限 |

#### 超时设定

**120 秒**【假设】
