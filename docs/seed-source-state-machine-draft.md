# 种子源状态机（评审草图）

根据[状态梳理清单](集中管控系统与分系统状态梳理清单.md)及讨论绘制，图源见 [Mermaid 状态机](diagrams/seed-source-state-machine-draft.mmd)。

当前图采用嵌套结构：外层为业务状态，内部状态描述该业务状态下的动作执行过程和结果。

- 未就绪：自检、功能检查的执行过程及失败重试。
- 就绪：参数下发、出光启动的执行过程及结果。
- 出光：参数采集的执行过程及结果；采集成功或失败均保持出光。
- 设备异常：独立故障确认事件进入，不由任务失败自动推断。

复位、关机、中止及恢复只画了完成确认后的转换；内部物理阶段和抢占规则尚待确认。
当前图也未定义自动超时转换。复合状态重新进入时进入图中指定的初始内部状态。

[新种子源仿真](../simulator/README.md)按本图实现，提供图与转换定义的一致性测试，以及 Taurus 原生桌面可视化。
既有 Java 双分系统 BPMN 和动作契约尚未迁移到这个模型。
