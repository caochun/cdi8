三、驱动与同步触发时序

sequenceDiagram
  participant MC as 总控
  participant SYNC as 集中同步(60)
  participant PP as 泵浦分系统(1)
  participant SW as 开关驱动源(1)
  participant ENV as 控制环境(1)

  Note over MC,ENV: ─── 发射充电阶段 ───
  MC->>PP: 发射充电指令
  MC->>ENV: 警灯+警示音乐开启
  PP-->>MC: 充电完成(75s±3s)
  ENV-->>MC: 音乐停止，警灯继续

  Note over MC,ENV: ─── 同步触发阶段(5秒) ───
  MC->>SYNC: T+0s 同步触发指令
  MC->>PP: T+0s 泵浦触发准备
  MC->>SW: T+0s 开关触发准备

  Note over SYNC: T+0s 倒计时开始 5...4...3...

  PP-->>SYNC: T+3s 泵浦触发就绪 ✅
  SW-->>SYNC: T+3s 开关触发就绪 ✅

  Note over SYNC: T+3s ...2...1...

  SYNC->>SYNC: T+5s 正式触发! 60束同步
  SYNC-->>MC: 触发完成

  Note over MC,ENV: ─── 预电离阶段(后处理中) ───
  MC->>PP: 预电离发射准备
  MC->>PP: 预电离发射充电(75s±3s)
  MC->>ENV: 警示音乐再次开启
  MC->>SYNC: 同步触发(预电离)
  MC->>PP: 泵浦触发准备(预电离)
  SYNC-->>MC: 预电离触发完成
关键约束：泵浦充电完成后不能长时间保持(安全风险)，必须尽快进入触发
T+3s 是硬约束：泵浦和开关必须在第3秒瞬间完成触发准备
异常处理：紧急停车 / 紧急触发 / 紧急泄放 / 紧急停充
