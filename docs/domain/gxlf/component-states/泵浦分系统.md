# 泵浦分系统状态定义

来源：`20261015集中管控系统与分系统状态梳理清单.xlsx`，工作表“分系统状态表”，第 50–63 行。

系统分类：发射/电源、激光链路。共 14 条定义，按原表行序排列。

字段及术语沿用原表，详见[拆分说明](README.md)。

原表说明：原表第 59–60 行的系统分类为“激光链路”，其余泵浦条目为“发射/电源”。本文件按同一控制对象汇总，并在各条目中保留原分类。

## 1. 开机自检

来源行：50（A50:H50）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 发射/电源 |
| 业务动作 | 开机自检 |
| 关键状态 | 未上电/离线 |
| 业务状态 | 未就绪 |

| 对流程影响 | 阻断相关业务节点，等待基础条件满足 |
