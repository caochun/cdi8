# 真空靶室分系统状态定义

来源：`20261015集中管控系统与分系统状态梳理清单.xlsx`，工作表“分系统状态表”，第 146–148、150–155 行。

系统分类：靶场/真空。共 9 条定义，按原表行序排列。

字段及术语沿用原表，详见[拆分说明](README.md)。

## 1. 开机自检

来源行：146（A146:H146）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 靶场/真空 |
| 业务动作 | 开机自检 |
| 关键状态 | 未上电/离线 |
| 业务状态 | 未就绪 |
| 关键状态描述 | 真空靶室分系统正在进行上电、连通和自检，尚无业务资格；全部通过后转为就绪。 |
| 关键状态判定条件（由分系统判断） | 电源/心跳/服务可达任一关键项不满足，且未处于可执行服务状态 |
| 对流程影响 | 阻断相关业务节点，等待基础条件满足 |

## 2. 功能检查

来源行：147（A147:H147）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 靶场/真空 |
| 业务动作 | 功能检查 |
| 关键状态 | 业务就绪完成（真空与联锁可用） |
| 业务状态 | 就绪 |
| 关键状态描述 | 真空靶室分系统已通过功能检查并具备规定业务能力；关键能力或联锁失效时退出就绪。 |
| 关键状态判定条件（由分系统判断） | 基础服务运行正常、自检通过、功能检查通过，该分系统关键能力均满足节点前置要求，是业务执行的门禁；设备回到可安全接收下一次流程的初始位/待机位，且无未清故障、无未释放资源锁 |
| 对流程影响 | 避免通用状态误判为业务可执行，导致节点提前下发 |

## 6. 通用异常处置

| 对流程影响 | 阻断当前节点及依赖节点，流程暂停 |
