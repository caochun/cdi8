# 多程放大系统状态定义

来源：`20261015集中管控系统与分系统状态梳理清单.xlsx`，工作表“分系统状态表”，第 39–49、149 行。

系统分类：激光链路。共 12 条定义，按原表行序排列。

字段及术语沿用原表，详见[拆分说明](README.md)。

原表说明：原表第 149 行“真空度保持”的控制对象为“多程放大系统”、系统分类为“激光链路”。本文件按原表归属保留，未将其移入真空靶室分系统。

## 1. 开机自检

来源行：39（A39:H39）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 激光链路 |
| 业务动作 | 开机自检 |
| 关键状态 | 未上电/离线 |
| 业务状态 | 未就绪 |
| 关键状态描述 | 多程放大系统正在进行上电、连通和自检，尚无业务资格；全部通过后转为就绪。 |
| 关键状态判定条件（由分系统判断） | 电源/心跳/服务可达任一关键项不满足，且未处于可执行服务状态 |
| 对流程影响 | 阻断相关业务节点，等待基础条件满足 |

| 对流程影响 | 避免通用状态误判为业务可执行，导致节点提前下发 |
