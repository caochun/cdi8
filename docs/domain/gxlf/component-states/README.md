## 字段与整理方式

下列字段说明直接取自原表表头。各文件使用简写字段名“关键状态”“业务状态”，正文保留原表字段值。

| Excel 列 | 原表表头 |
| --- | --- |
| A | 系统分类 |
| B | 控制对象 |
| C | 业务动作 |
| D | 关键状态<br>（业务动作执行完成后分系统反馈的动作执行结果状态） |
| E | ⭐业务状态<br>（流程运行中各分系统保持的业务状态） |
| F | 关键状态描述 |
| G | 关键状态判定条件（由分系统判断） |
| H | 对流程影响 |

“控制对象”作为文件标题，其余七列逐条列出。单元格内换行保留为表格内换行；真正的空单元格标为“（原表留空）”；合并单元格的共用内容展开至对应条目。

本目录保留原表的“业务状态”“关键状态”等术语和定义，不据此补充状态迁移或改写现有 SCXML 模型。
