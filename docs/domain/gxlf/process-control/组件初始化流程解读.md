# 组件初始化流程（历史方案）

本文保留上一阶段初始化流程的历史说明。旧的两个可执行 BPMN 已删除；当前主干设计见 [`gxlf_shot_run_backbone.bpmn20.xml`](../../../../examples/gxlf/design/gxlf_shot_run_backbone.bpmn20.xml)，不能把本文当作当前执行约束。

当前设施结构见[系统定义模型设计](系统定义模型设计.md)。其中只声明组件类型、实例集合、能力、接口、拓扑和不变量。组件初始化如何读取设备状态、如何建立设施状态投影、如何把本发证据写入发次运行模型，需要在后续模型中重新定义。

保留这两个 BPMN 的原因是保存业务流程草稿和设备动作名称，待设施状态投影与发次运行模型完成后再迁移。迁移时应把：

- 上电检查和功能检查的设备动作留在 BPMN 与设备 SCXML 的协作中；
- `powered`、`ready` 等整体事实交给设施状态投影；
- 初始化是否属于某一发次、参数是否已接收和证据是否完整交给发次运行模型；
- 流程是否可以继续由 BPMN 同时检查设施事实和发次证据。
