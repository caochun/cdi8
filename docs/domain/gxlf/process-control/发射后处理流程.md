# 发射后处理流程

本阶段从“正式发射完成”开始，当前仅在[实验主干设计 BPMN](../../../../examples/gxlf/design/gxlf_experiment_backbone.bpmn20.xml)中保留业务结构，尚未接入可执行的十四类设备流程。

正式发射完成后，流程并行执行以下后处理分支：

- 物理诊断分系统后处理；
- 所选种子源和二倍频组件的激光参数采集；
- 再生与双程放大组件的能量数据采集，随后进入预放待机；
- 主发射后泵浦数据采集、泵浦待机、预电离发射准备、警示音乐开启、预电离充电、警示音乐停止、同步倒计时、泵浦触发准备、同步触发、预电离后数据采集、预电离后待机和警灯关闭；
- 测量取样的激光参数采集、靶瞄数据分析；
- 靶瞄收靶；
- 放电波形采集、开关待机；
- 片放吹扫。

当前四类 SCXML 模型只覆盖其中的光源参数采集、预放能量采集和预放待机。其他分系统尚未建立独立状态机，因此由 `contextTargets` 中的演示条件设备提供显式条件证据；条件为 false 时流程停留在对应等待节点。

所有后处理分支完成后，流程等待“靶场中子屏蔽门打开”，再执行结果核验。结果核验确认外部条件全部完成，所选光源处于 `collectionOk`，再生与双程放大处于 `standbyReady`，多程放大仍处于 `collimationReady`。屏蔽门是否必须等待所有后处理分支，是业务说明中的待确认项；当前模型采用全部分支汇合后再开门的验证口径。
