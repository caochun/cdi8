# GXLF 系统状态模型设计（历史方案）

> 本文保留上一阶段的综合 `system-state-model` 设计记录。该模型已经删除，内容不再作为当前系统的权威定义。

当前权威模型是[系统定义模型设计](系统定义模型设计.md)和 [`gxlf-facility.system-definition.xml`](../../../../examples/gxlf/system/gxlf-facility.system-definition.xml)。它描述设施组成、设备能力、接口、拓扑和系统不变量，不描述 `powered`、`initialized`、`configured` 等运行阶段。

设备状态仍由 [`examples/gxlf/components/`](../../../../examples/gxlf/components/) 下的 SCXML 表达。设施运行状态现在由 [`gxlf-facility-state-projection.xml`](../../../../examples/gxlf/system/gxlf-facility-state-projection.xml) 声明并由基础运行时计算；某次发射的阶段和证据由 [`shot-run.schema.json`](../../../../contracts/shot-run.schema.json) 定义。`examples/gxlf/design/` 中的新发次主干仍是不可执行设计，不能把历史综合模型恢复为运行入口。
