## 第一阶段：发射准备阶段

```
T01  发射任务创建
      │
T02  参数反演生成配方参数
      │
T03  实验任务参数下发
      │
T04  ┌─ 测量重频配方（集中同步）
     └─ 预放重频配方（集中同步）
      │（等待两路均完成）
T05  ┌─ 种子源出光（光纤种子源组件）
     ├─ 二倍频出光（二倍频宽带激光注入组件）
     ├─ 预放唤醒（再生与双程放大组件）
     ├─ 清场（安全联锁）
     ├─ 测量靶瞄准备（测量取样组件）
     ├─ 实验靶预定位（靶瞄准定位系统）
     └─ 泵浦发射准备（泵浦分系统）
      │（等待全部完成）
T06  ┌─ 门关闭（安全联锁）
     └─ 风淋门锁住（安全联锁）        ← 进入安全管控状态
      │
T07  ┌─ 能量粗闭环（再生与双程放大组件）
     ├─ 片放吹扫（冷却分系统）
     └─ 模拟靶定位（靶瞄准定位系统）
      │
T08  ┌─ 诊断设备状态确认（物理实验诊断分系统）
     └─ 光路准直（多程放大系统）
      │
T09  ┌─ 能量精闭环（再生与双程放大组件）
     └─ 进入重频光状态（多程放大系统）
      │
T10  光束引导（靶瞄准定位系统）
      │
T11  ┌─ 进入打靶状态（多程放大系统）
     └─ 测量打靶运动准备（测量取样组件）
      │
     [进入发射阶段]
```

**阶段说明**：
- T04 同步配方必须先于 T05 各分系统准备下发，确保重频时序参数就绪
- T05 是最大并发点（7 路并行）；种子源/二倍频任一出光失败，流程熔断
- T06 门关闭标志安全管控状态正式建立，此后场地人员无法进入
- T07 模拟靶定位与能量粗闭环并行，互不依赖
- T10 光束引导单独串行，是打靶准备的关键门控节点

## 第二阶段：发射阶段

```
T01  ┌─ 诊断设备采集设置（物理实验诊断分系统）
     ├─ 晶体位姿设置（频率转换分系统）
     ├─ 发射充电准备（泵浦分系统）
     ├─ 开关充电（开关驱动源组件）
     └─ 能量精闭环（再生与双程放大组件）
      │
T02  预放单次配方（集中同步分系统）
      │
T03  ┌─ 打靶测量准备（测量取样组件）
     └─ 能量计清零（再生与双程放大组件）
      │
T04  发射充电（泵浦分系统）          ← 充电进程由泵浦主动上报
      │
T05  ┌─ 泵浦触发准备（泵浦分系统）
     ├─ 开关触发准备（开关驱动源组件）
     └─ 同步触发（集中同步分系统）    ← 实际出光，发次完成
```

**阶段说明**：
- T01 并行启动 5 路准备，最长路径决定 T01 总耗时（约 10–15 s）
- T02 预放单次配方是单次发射的同步参数下发，必须串行在 T01 之后
- T04 发射充电期间，泵浦分系统通过 `ChargeProgressReport` 推送接口实时上报进度；若泵浦触发自我保护，调用 `EmergencyStop` 通知集中管控
- T05 三路触发信号须由集中同步在同一时序窗口内下发，`同步触发` 是最终门控

## 第三阶段：发射后处理阶段

```
T01  ┌─ 种子源激光参数采集（光纤种子源组件）
     ├─ 二倍频激光参数采集（二倍频宽带激光注入组件）
     ├─ 能量数据采集（再生与双程放大组件）
     ├─ 放电波形采集（开关驱动源组件）
     ├─ 激光参数采集（测量取样组件）
     ├─ 靶瞄收靶（靶瞄准定位系统）
     ├─ 片放吹扫（冷却分系统）
     └─ 数据采集入库（集中管控平台）
      │
T02  ┌─ 物理诊断分系统后处理（物理实验诊断分系统）
     └─ 高压电源退电/DIM复位（泵浦分系统）
      │
T03  ┌─ 预放待机（再生与双程放大组件）
     ├─ 靶瞄数据分析（靶瞄准定位系统）
     ├─ 模型参数计算（运行参数获取与性能模型校准）
     └─ 开关待机（开关驱动源组件）
      │
T04  预电离发射准备（泵浦分系统）     ← 为下一发预电离充电做准备
      │
T05  预电离发射充电（泵浦分系统）
      │
T06  ┌─ 泵浦触发准备（泵浦分系统）
     └─ 同步触发（集中同步分系统）    ← 预电离触发（非主发射）
      │
T07  泵浦数据采集（泵浦分系统）
      │
T08  ┌─ 泵浦待机（泵浦分系统）
     └─ 退出安全管控状态（安全联锁）
      │
     [本发次结束，等待下一发次或结束日计划]
```

**阶段说明**：
- T01 是最大并发采集点（8 路），在出光后立即启动，对时序精度要求高
- T03 模型参数计算（`ModelParamCalc`）使用本发采集数据更新下发参数模型，结果供下一发参数反演使用
- T04–T06 预电离序列是独立的电气操作，不影响激光数据处理，可与 T03 部分重叠
- T08 退出安全管控后，场地人员方可进入，本发次闭环完成

```

        ↓（同步触发完成）

        ↓（退出安全管控）

```

## 涉及分系统汇总

| 分系统 | 参与阶段 | 关键操作 |
|--------|----------|---------|
| 光纤种子源组件 | 准备、后处理 | 出光、参数采集、待机 |
| 二倍频宽带激光注入组件 | 准备、后处理 | 出光、参数采集、待机 |
| 再生与双程放大组件 | 准备、发射、后处理 | 唤醒、粗/精闭环、单次配方、能量采集、待机 |
| 多程放大系统 | 准备 | 光路准直、重频/打靶状态确认 |
| 开关驱动源组件 | 发射、后处理 | 充电、触发准备、波形采集、待机 |
| 泵浦分系统 | 准备、发射、后处理 | 发射准备、充电准备、充电、触发准备、预电离、数据采集、待机 |
| 测量取样组件 | 准备、发射、后处理 | 靶瞄准备、打靶测量准备、激光参数采集、待机 |
| 频率转换分系统 | 发射 | 晶体位姿设置 |
| 靶瞄准定位系统 | 准备、后处理 | 实验靶预定位、模拟靶定位、光束引导、收靶、数据分析 |
| 物理实验诊断分系统 | 准备、发射、后处理 | 状态确认、采集设置、后处理 |
| 集中同步分系统 | 准备、发射、后处理 | 重频配方、单次配方、同步触发、预电离触发 |
| 冷却分系统 | 准备、后处理 | 片放吹扫 |
| 安全联锁 | 准备、后处理 | 清场、门控、安全管控状态进/退 |
| 运行参数与模型校准 | 后处理 | 模型参数计算 |
