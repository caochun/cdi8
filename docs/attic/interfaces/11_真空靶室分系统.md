## 接口详细定义

### 抽真空

**Tango Command**：`VacuumPump`
**触发阶段**：发射准备阶段、发射阶段

**描述**：接收集中管控下达的靶室真空抽气任务。收到指令后分系统执行：控制模式→自动→系统自检→功能检查→执行抽气→返回结果。

#### 输入参数

| 参数名 | JSON 字段 | Tango 类型 | 描述 | 取值 |
|--------|----------|-----------|------|------|
| 控制指令 | `pump_cmd` | DevShort | 抽气控制 | 0=无效；1=启动；2=停止 |

#### 输出

| 返回值 | Tango 类型 | 描述 |
|--------|-----------|------|
| 接收状态 | DevShort | 见状态码 |

#### 状态码

| 值 | 含义 |
|---|---|
| 0 | 失败 |
| 1 | 收到，系统自检未通过 |
| 2 | 收到，系统自检通过，功能检查未通过 |
| 3 | 收到，系统自检通过，功能检查通过，真空抽气流程启动中 |

#### 超时设定

**600 秒**【假设，抽真空过程耗时较长】

#### 失败处理

集中管控侧收到失败状态后，默认最多重试 **1 次**，重试间隔 **3s**；仍失败则终止当前发次流程并上报告警。【假设】

### 真空度反馈

**Tango Attribute**：`VacuumLevelOk`（只读）【假设接口类型为 Attribute】
**触发阶段**：发射准备阶段、发射阶段、后处理阶段

**描述**：集中管控通过轮询或事件订阅读取该属性，判断当前真空度是否满足工作真空度要求。

| 属性名 | Tango 类型 | 描述 | 取值 |
|--------|-----------|------|------|
| `VacuumLevelOk` | DevBoolean | 当前真空度是否满足要求 | false=不满足；true=满足 |

**备注**：轮询周期【假设】5s；不满足时集中管控暂停发射准备阶段等待达标。

### 数据存储共享

**接口类型**：数据库接口（非 Tango Command）

真空靶室分系统通过数据库向集中管控共享以下数据：

| 数据项 | 建议字段名 | 类型 | 描述 |
|--------|-----------|------|------|
| 真空度 | `vacuum_level_pa` | DOUBLE | 当前靶室真空度（Pa） |
| 真空度是否达标 | `vacuum_ok` | BOOLEAN | 是否满足工作要求 |
| 真空阀门状态 | `valve_status` | INT | 各阀门开关状态 |
| 水汽捕集泵状态 | `cryo_trap_status` | INT | 运行状态 |
| 干泵机组状态 | `dry_pump_status` | INT | 运行状态 |
| 低温泵状态 | `cryo_pump_status` | INT | 运行状态 |
| 设备故障 | `fault_code` | INT | 故障码（0=无故障） |
| 更新时间 | `updated_at` | DATETIME | 数据更新时间戳 |

> 具体表名和字段名待与数据库设计对齐。【假设】
