## 约定

### Tango 参数编码
- 多参数输入统一编码为 **JSON 字符串（DevString）**
- 输出状态码类型为 **DevShort**（除诊断分系统的复杂接口外）
- 复杂输出编码为 **JSON DevString**

### 通用输入参数

| 参数名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| 任务编号 | `task_id` | DevLong | 本次下发任务唯一标识 |
| 发次编号 | `shot_id` | DevLong | 发次唯一标识 |
| 阶段编号 | `phase_id` | DevShort | 发射三阶段（1/2/3） |
| 束线编号 | `beamline_id` | DevShort | 目标束线（1~N） |

### 通用状态码

| 值 | 含义 |
|---|---|
| 0 | 失败 / 异常 |
| 1 | 收到（已接受指令） |
| 2 | 无服务权限 |

### 默认失败处理
最多重试 **1 次**，重试间隔 **3s**；仍失败则终止当前发次并上报告警。
**同步触发**失败后不重试，立即上报。
