# GXLF 实验平台领域背景

## 一、什么是 GXLF

GXLF 是中国工程物理研究院激光聚变研究中心（中物院八所）建设的一座**激光惯性约束聚变（ICF）实验装置**。它与美国国家点火设施（NIF）、法国兆焦耳激光装置（LMJ）属于同一类设施——通过多束高功率激光同时照射一个微型靶丸，在极短时间内将靶丸压缩到极高密度和温度，触发热核聚变反应。

这类装置的核心物理过程：

```
多束激光 → 聚焦到靶球中心 → 靶丸被辐照压缩
→ 内爆 → 中心区域达到聚变条件 → 产生中子和能量
```

GXLF 装置规模：**60束激光束线**，分布在多个扇区，汇聚到一个真空靶室中心。

辅助系统：

- **集中同步分系统**：66路同步触发信号，确保所有束线在纳秒精度内同时发射
- **泵浦分系统**：为片状放大器的闪光灯提供脉冲大电流（充电电压 kV 级，电容器组储能），是整个装置最危险的部分（能库火灾/爆炸风险）
- **冷空分系统**：片放吹扫（闪光灯发射后放大器玻璃片需要冷却吹扫）+ 灯箱充气冷却
- **测量取样组件**：62路在线测量，采集各束线的能量、波形、近场、远场、波前等激光参数
- **LD靶分系统**：低温氘（Liquid Deuterium）靶的专用支撑和开罩系统，比常温靶工艺复杂得多
- **安全联锁系统**：屏蔽门、警灯、紧急停机开关、RFID人员计数——靶场区域在发射时有中子辐射和X/γ射线

## 三、一次"打靶"（Shot）的完整生命周期

一次打靶称为一个**发次**，编号规则如 `SY20260205001`。

### 阶段 A：发射准备

目标：让装置从空闲状态进入"一切就绪，等待扣扳机"的状态。

```
时序（简化）：
片放吹扫（如果上一发的吹扫延续）
  → 种子源出光 + 二倍频出光         ← 激光源开始工作
  → 预放唤醒 → 预放出打靶光         ← 预放大器启动
  → 光路准直（60+束并行）            ← 主放大光路校准
  → 能量粗闭环 → 能量精闭环         ← 自动调节到目标能量
  → 重频光状态确认                   ← 重频模式下持续出光验证
  → 晶体位姿调整（60+束并行）       ← 频率转换晶体精密角度
  → 实验靶预定位 → 模拟靶定位       ← 靶瞄系统定位
  → 光束引导（将激光对准靶心）
  → 同步配方下发（发射准备配方、重频配方等）
  → 集中同步自检

  诊断系统：
    → 诊断设备状态确认               ← DIM伸出、设备定位瞄准
    → 诊断设备参数配置               ← 高压加载、采集参数设置
    → 真空度确认
```

### 阶段 B：发射

目标：真正的打靶发射，从清场到扣下扳机，持续仅几分钟。

```
时序：
  清场（RFID确认靶场无人）
  → 屏蔽门关闭锁定
  → 警灯亮起 + 警示音乐播放
  → 安全联锁进入管控状态
  → 泵浦发射准备 → 发射充电准备     ← 电容器组开始充电（最危险阶段）
  → 发射充电（充电进程实时反馈）    ← 充电到目标电压（kV级）
  → 打靶状态确认（全系统最终确认）
  → 能量计清零
  → 同步配方切换为单次
  → 预放单次配方 + 测量单次配方
  → 同步触发 !!!                     ← 这一刻，60束激光同时发射

  诊断系统（发射同步）：
    → 数据采集（相机/示波器/光谱仪同步触发采集）

  紧急中止可能来自：
    - 泵浦紧急停充（充电异常）
    - 安全联锁触发（人员闯入/屏蔽门异常）
    - 集中管控系统主动中止
```

**同步触发**是整个发射的关键时刻——集中同步分系统发出触发信号，所有束线在纳秒精度内同时出光，脉冲持续仅纳秒量级。

### 阶段 C：发射后处理

目标：采集实验数据、设备安全复位、准备下一发。

```
时序：
  数据采集阶段：
    → 激光参数采集（60+路能量/波形/近场/远场/波前）
    → 诊断设备数据采集（X射线图像、中子产额、散射光...）
    → 泵浦数据采集 + 放电波形采集
    → 靶瞄数据分析
    → 模型参数计算（性能模型校准）

  设备复位阶段：
    → 诊断设备发射后处理（退高压、DIM收回、设备下电）
    → 泵浦关机复位
    → 各系统进入待机
    → 实验靶复位 / 收LD靶 / 靶瞄收靶
    → 片放吹扫启动（冷却片状放大器，持续15分钟）
    → 安全联锁退出管控状态
    → 屏蔽门解锁 + 警灯熄灭

  报告阶段：
    → 智能发射报告生成（PDF/Word）
```

## 四、运行节奏

常规运行期（约10个月/年）：**每天约10个发次**，发次间隔控制在1小时。

```
┌─────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│发次1 │发次2 │发次3 │发次4 │发次5 │发次6 │发次7 │发次8 │发次9 │发次10│
├──┬──┼──┬──┼──┬──┼──┬──┼──┬──┼──┬──┼──┬──┼──┬──┼──┬──┼──┬──┤
│A │B│C│A │B│C│...                              │A │B│C+吹扫│
│  │ │ │  │ │ │                                  │  │ │ +自检 │
└──┴──┴──┴──┴──┴──┴───────────────────────────────┴──┴──┴──────┘
         片放吹扫可跨发次延续
```

每天第一发的后处理吹扫延续到第二发的准备阶段；最后一发执行完整75分钟后处理（含片放吹扫、状态恢复、条件自检）。

运行岗位配置：3人/班（运行负责人 + 值班长 + 总控运行岗）。

## 六、关键领域概念

| 概念 | 含义 |
|------|------|
| 束线 | 一路独立的激光光路，GXLF有60束，每束可独立配置能量/波形/脉宽 |
| 发次 | 一次打靶发射，编号如 SY20260205001，含三阶段（A准备/B发射/C后处理）|
| 靶丸 | 微型球壳（直径数百μm），充填氘氚燃料，是聚变的"燃料胶囊" |
| 常温靶 / LD靶 | LD靶需要低温环境（液氘），工艺更复杂，有专用开罩机构 |
| 片放 | 片状放大器（Slab Amplifier），主放大器中的钕玻璃片，发射后需要吹扫冷却 |
| 泵浦 | 为片放闪光灯提供能量的脉冲功率系统，电容器组充电到kV级 |
| 频率转换 | 用KDP晶体将1053nm基频光→351nm三倍频光，晶体角度需μrad级精密调整 |
| DIM | 诊断插入机构（Diagnostic Instrument Manipulator），可伸入靶室内部的机械手 |
| 靶瞄 | 靶瞄准定位系统，确保每束激光精确打到靶丸指定位置（μm精度）|
| 同步触发 | 集中同步分系统发出的触发信号，确保60束在纳秒精度内同时出光 |
| 能量闭环 | 通过测量预放输出能量，自动调节种子源参数，使输出达到目标能量 |
| 束间同步时序 | 多束激光在时间维度的严格对齐，通过示波器测量三倍频数据计算偏差 |
| 参数反演 | 给定期望输出能量/波形，通过虚拟光路仿真反推种子源输入参数 |
| 服务权限 | Tango设备的控制权管理：预约→签到→控制→签退，集中管控拥有最高权限 |

## 七、为什么需要这样的软件架构

这类大型激光聚变装置的控制复杂度来自几个维度：

1. **规模**：60束 × 每束十几个设备 = 上千个设备节点，365个系统服务
2. **并行性**：60束激光各自独立准备，最终纳秒级同步发射
3. **安全性**：泵浦充电kV级（爆炸风险）、靶场中子辐射（人员防护）、DIM碰撞（μm级空间约束）
4. **精度**：能量控制到J级、时序控制到ns级、定位控制到μm级
5. **节奏**：每天10发，发次间隔1小时，需要高度自动化
6. **诊断复杂度**：每发产生海量异构数据（图像/波形/光谱），需要实时采集、对比分析

集中管控系统解决的是"**如何协调14个分系统在正确的时间做正确的事**"；诊断系统解决的是"**如何让几十台异构诊断设备在打靶瞬间精确采集到物理数据**"。两者通过标准化的 Tango 接口契约解耦，各自管理自己的 DAG 流程。
