# GXLF 激光聚变实验——完整场景还原

> 基于集中管控系统需求分析报告和物理实验诊断系统需求分析报告还原。

## 这是什么实验

GXLF 是一个激光驱动惯性约束聚变（ICF）实验装置。核心原理：用多束高功率激光同时照射一个微米级靶丸，通过辐照驱动靶丸内爆，产生聚变反应。整个装置要解决的问题是——如何让几十束激光在纳秒级精度内同时到达靶丸，且能量均匀。

## 激光的一生：从种子到打靶

```
种子光 → 注入整形 → 预放大 → 主放大 → 频率转换 → 传输聚焦 → 靶室打靶
 6束      6束        10束      61束      61束                    1个靶丸
```

**光纤种子源组件**（6束）：产生最初的低功率激光脉冲种子。这是整个激光链路的起点，脉冲波形在这里就被精确定义了。

**二倍频宽带激光注入组件**（6束）：对种子光进行宽带注入和整形，为后续放大做准备。

**再生与双程放大组件**（10束）：预放大阶段。种子光在这里被放大到中等功率。这个环节有能量闭环控制——粗闭环和精闭环，确保每束激光的能量在目标范围内。

**多程放大分系统**（61束）：主放大阶段。激光在大口径钕玻璃片中多次通过，功率被放大到极高水平。这里需要光路准直确保光束质量。从 10 束扩展到 61 束，说明有分束和并行放大。

**开关驱动源组件**：驱动电光开关（Pockels Cell），控制激光脉冲的通断和时序。充电→触发是关键动作。

**泵浦分系统**（2套）：为主放大器提供泵浦能量（闪光灯或二极管泵浦）。发射充电是整个发射流程中耗时最长的环节之一，充电过程中泵浦系统实时上报进度，且有紧急停充保护。

**频率转换分系统**（61束）：将基频激光（1053nm 红外）转换为二倍频（527nm 绿光）或三倍频（351nm 紫外）。通过调整 KDP 晶体的位姿角度来实现。

**集中同步分系统**（66套）：确保所有束线的激光脉冲在纳秒级精度内同时到达靶丸。通过示波器测量三倍频信号做偏差计算，反馈给种子源调整 AWG 出光时序。

**测量取样组件**（62套）：在激光链路的关键位置取样测量——近场分布、远场分布、能量、时间波形、波前等参数，用于实时监控和事后分析。

**冷却/管路分系统**（2套）：光学元件冷却。主放大器的钕玻璃片在每次发射后会积累热量，需要片放吹扫冷却（约15分钟），这是限制重频发射间隔的关键因素之一。

## 靶场：激光汇聚的终点

**靶瞄准定位分系统**：将微米级靶丸精确定位到靶室中心（靶室中心坐标系），然后引导所有激光束线对准靶丸。光束引导是发射准备的关键门控节点——引导不完成，不能进入发射阶段。

**真空靶室分系统**：维持靶室的高真空环境。激光打靶必须在真空中进行（避免空气击穿和能量损耗）。真空度是安全联锁的关键参数。

**LD靶分系统**（25套）：管理低温靶（Layered D₂ 靶，氘冰层靶）。这种靶需要在极低温下维持均匀的冰层，有开罩/复位/收靶等机械动作。

**安全联锁**：靶场是辐射区域（中子、X射线、γ射线）。发射前必须清场、关闭屏蔽门、确认人员全部撤离（RFID 计数清零）。屏蔽门与泵浦电源联锁——门没关好，充电不允许启动。10个紧急停机开关分布在靶场防护门内侧、出中子区域和控制台。

## 靶场物理布局

```
激光大厅（负一层）
├─ 种子源同步间：光纤种子源(6束) + 集中同步(16套)
├─ 电控区：预放大配电 + 管路吹扫 + 开关驱动源(30套)
├─ 冷空间：冷却控制
└─ 一层束线上：二倍频注入(30套) + 频率转换 + 多程放大 + 测量取样 + 靶瞄控制

靶场区域
├─ 靶场一层：集中同步(1套)
├─ 靶场零层（靶室）
│  ├─ 靶球（中心）—— 微米级靶丸
│  ├─ 靶支撑及中心定位控制
│  ├─ 真空机组
│  ├─ DIM搭载平台(×3) —— 可伸入靶室，搭载诊断设备到靶球附近
│  ├─ 光学诊断组件 —— 安装在靶室法兰上
│  ├─ X射线成像组件 —— 安装在靶室法兰上
│  ├─ 闸板阀 —— 真空隔离
│  └─ 屏蔽门 —— 中子防护
├─ 靶场负一层：传输聚焦 + 时间波形测量
└─ 靶场四周：核诊断组件（中子探测器）

P1能库
└─ 泵浦分系统现场监控
```

## 诊断系统：实验的"眼睛"

诊断设备分布在靶球周围，在激光打靶的瞬间和前后捕捉物理信号：

**光学诊断组件**——安装在靶室法兰上：
- 全孔径背向散射测量模块（×2）：用门控相机、光谱仪、条纹相机、示波器测量激光打靶后的背向散射光，诊断束靶耦合效率（有多少激光能量真正被靶丸吸收）
- 近背向散射光测量模块（×2）：用门控相机和标定模块测量近角度散射光

**X射线成像组件**——安装在靶室法兰上：
- 静态成像模块（×2）：用 CMOS 相机拍摄 X 射线静态图像，诊断辐照均匀性
- 分幅成像模块（×3）：用分幅相机拍摄 X 射线时间分辨图像，诊断内爆对称性
- 显微成像模块（×3）：用 KB 显微镜（Kirkpatrick-Baez）获取高分辨 X 射线图像

**核诊断组件**——分布在靶场区四周：
- 中子产额测量模块（×1）：用示波器和高压电源驱动的探测器测量聚变中子产额
- 离子温度测量模块（×3）：通过中子飞行时间测量离子温度，表征内爆综合性能
- 中子 Bangtime 测量模块（×1）：测量中子产生的精确时刻

**诊断搭载机械手（DIM）**——可深入靶室内部：
- 通用搭载模块（×3）：DIM 搭载平台可以伸入靶室，将诊断设备送到靶球附近的精确位置。配有激光跟踪仪定位、摆阀和真空机组维持局部真空
- 真空内操作手（×3）：在真空环境中进行靶室内部操作

诊断系统回答的核心问题是：**这一发打得怎么样？**
- 束靶耦合效率多少？（背向散射光测量）
- 辐照是否均匀？（X射线成像）
- 内爆是否对称？（分幅成像）
- 聚变产额多少？离子温度多少？（核诊断）

这些数据是物理实验的最终产出，也是评判实验成功与否的依据。

## 软件控制体系

```
集中管控系统（总控）
├─ 运维任务管控组件 —— 调度14个分系统完成发射流程
├─ 状态监控组件 —— 监控所有设备状态、环境、健康度
└─ 控制环境组件 —— 远程开关机(120+套电控柜)、安全联锁

    ↕ Tango接口（总控-系统服务层）

14个分系统的系统服务软件（含物理实验诊断系统）

    ↕ Tango接口（系统服务-设备服务层）

各设备服务软件（示波器、相机、高压电源、DIM等的Device Server）

    ↕ 硬件通信

物理设备
```

采用"总控-系统服务-设备服务"三层控制结构。集中管控系统只和系统服务层对话，不直接操控设备。

## 一次发射的完整时间线

### 日计划阶段（发射前数天~数小时）

1. 物理方提交实验需求（靶型、能量水平、诊断需求）
2. 运行组智能排程，生成日工作计划，发布打靶通知单
3. 诊断值班长接收任务，提前配置参试设备、绑定流程配方、调整诊断参数

### 开机自检（当日首次）

1. 控制环境组件远程开启约 120+ 套电控柜
2. 所有分系统执行开机自检，上报状态
3. 功能检查

### 发射准备阶段（A阶段）

```
T01  发射任务创建
T02  参数反演生成配方参数
T03  实验任务参数下发
T04  同步配方下发（测量重频配方 + 预放重频配方）
T05  7路并行准备（最大并发点）：
     ├─ 种子源出光
     ├─ 二倍频出光
     ├─ 预放唤醒
     ├─ 清场（安全联锁）
     ├─ 测量靶瞄准备
     ├─ 实验靶预定位
     ├─ 泵浦发射准备
     └─ 片放吹扫
T06  门关闭 + 风淋门锁住 ← 进入安全管控状态，此后人员无法进入
T07  能量粗闭环 + 片放吹扫 + 模拟靶定位（并行）
T08  诊断设备状态确认 + 光路准直（并行）
T09  能量精闭环 + 进入重频光状态
T10  光束引导 ← 关键门控节点
T11  进入打靶状态 + 测量打靶运动准备
     → 进入发射阶段
```

### 发射阶段（B阶段）

```
T01  5路并行准备：
     ├─ 诊断设备采集设置 ← 诊断系统内部展开几十步精细流程
     ├─ 晶体位姿设置
     ├─ 发射充电准备
     ├─ 开关充电
     └─ 能量精闭环
T02  预放单次配方
T03  打靶测量准备 + 能量计清零
T04  发射充电 ← 泵浦实时上报充电进度
T05  泵浦触发准备 + 开关触发准备 + 同步触发 ← 激光出光，打靶！
```

诊断系统在 T01 收到 `DiagCollectSetup` 后，内部展开的流程：
```
DIM伸出 → 设备定位瞄准 → 设备参数配置 → 示波器接地 → 高压加载
→ 示波器采集参数配置 → 示波器DC耦合 → 读取设备状态
→ 等待触发信号 → 数据采集（相机/示波器/光谱仪同时采集）
```

### 发射后处理阶段（C阶段）

```
T01  8路并行数据采集：
     ├─ 种子源激光参数采集
     ├─ 二倍频激光参数采集
     ├─ 能量数据采集
     ├─ 放电波形采集
     ├─ 激光参数采集（测量取样）
     ├─ 靶瞄收靶
     ├─ 片放吹扫
     └─ 数据采集入库
T02  物理诊断分系统后处理 + 高压电源退电/DIM复位（并行）
T03  预放待机 + 靶瞄数据分析 + 模型参数计算 + 开关待机
T04  预电离发射准备 ← 为下一发做准备
T05  预电离发射充电
T06  泵浦触发准备 + 同步触发（预电离触发，非主发射）
T07  泵浦数据采集
T08  泵浦待机 + 退出安全管控状态
     → 本发次结束，等待下一发次或结束日计划
```

诊断系统在 T02 收到 `DiagShotPostProcess` 后，内部展开的流程：
```
数据采集完成确认 → 相机(CCD)回温 → 相机(CCD)关机
→ 高压卸载 → DIM收回 → DIM下电
→ 生成诊断实验报告
```

### 重频运行节奏

- 每日约 10 发，间隔约 1 小时
- 后处理阶段和下一发的准备阶段有重叠
- 片放吹扫约 15 分钟，是限制发射间隔的关键因素
- 运行岗位 3 人/班，目标是不间断自动化运行
- 常规运行约 10 个月/年，维护期约 2 个月/年

## 两套需求的关系

集中管控系统需求定义了装置级的全局编排——14 个分系统如何协作完成一次发射。物理实验诊断系统需求定义了诊断分系统内部的精细编排——几十台诊断设备如何协作完成一次诊断数据采集。

两者是嵌套关系：总控的发射流程 DAG 中，诊断系统只占 3 个节点（状态确认、采集设置、后处理）；但每个节点背后，诊断系统内部展开的是十几步的设备操控流程。

```
总控发射流程（外层，跨14个分系统）
  ├─ T08 DiagStatusConfirm → 诊断系统内部：遍历所有参试设备检查状态
  ├─ T01 DiagCollectSetup  → 诊断系统内部：DIM伸出→定位→参数配置→高压加载→采集就绪
  └─ T02 DiagShotPostProcess → 诊断系统内部：数据采集→回温→高压卸载→DIM收回→下电
```

总控是"指挥官下达命令"，诊断系统是"部队接到命令后的具体作战方案"。
