# 控制环境组件状态定义

来源：`20261015集中管控系统与分系统状态梳理清单.xlsx`，工作表“分系统状态表”，第 178–185 行。

系统分类：环境/安防。共 8 条定义，按原表行序排列。

字段及术语沿用原表，详见[拆分说明](README.md)。

## 1. 自检

来源行：178（A178:H178）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 环境/安防 |
| 业务动作 | 自检 |
| 关键状态 | 未上电/离线 |
| 业务状态 | 未就绪 |
| 关键状态描述 | 电源/心跳/服务可达任一关键项不满足，且未处于可执行服务状态 |
| 关键状态判定条件（由分系统判断） | 阻断相关业务节点，等待基础条件满足 |
| 对流程影响 | 当前节点处于执行/等待态，后续依赖节点不得提前下发 |

## 2. 自检通过、待机

来源行：179（A179:H179）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 环境/安防 |
| 业务动作 | 自检通过、待机 |
| 关键状态 | 业务就绪（具备清场、屏蔽门权限控制能力） |
| 业务状态 | 就绪 |
| 关键状态描述 | 基础服务运行正常、自检通过，该分系统关键能力均满足节点前置要求，是业务执行的门禁；设备回到可安全接收下一次流程的初始位/待机位，且无未清故障、无未释放资源锁 |
| 关键状态判定条件（由分系统判断） | 避免通用状态误判为业务可执行，导致节点提前下发 |
| 对流程影响 | 业务就绪确认 |

| 系统分类 | 环境/安防 |
