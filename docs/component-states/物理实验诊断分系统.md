# 物理实验诊断分系统状态定义

来源：`20261015集中管控系统与分系统状态梳理清单.xlsx`，工作表“分系统状态表”，第 104–115 行。

系统分类：测量/诊断。共 12 条定义，按原表行序排列。

字段及术语沿用原表，详见[拆分说明](README.md)。

## 1. 开机自检

来源行：104（A104:H104）。

| 字段 | 定义 |
| --- | --- |
| 系统分类 | 测量/诊断 |
| 业务动作 | 开机自检 |
| 关键状态 | 未上电/离线 |
| 业务状态 | 未就绪 |
| 关键状态描述 | 物理实验诊断分系统正在进行上电、连通和自检，尚无业务资格；全部通过后转为就绪。 |
| 关键状态判定条件（由分系统判断） | 电源/心跳/服务可达任一关键项不满足，且未处于可执行服务状态 |
| 对流程影响 | 阻断相关业务节点，等待基础条件满足 |
