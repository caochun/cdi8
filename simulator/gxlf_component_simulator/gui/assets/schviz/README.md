These browser assets are vendored for the native Qt GUI.

- `schviz.min.js`: `@scion-scxml/schviz` 3.2.28, Apache-2.0
- `scxml.min.js`: `@scion-scxml/scxml` 4.3.28, Apache-2.0
- `react.min.js`, `react-dom.min.js`: React 15.6.2, MIT
- `polyfill.min.js`: `babel-polyfill` 6.26.0, MIT

The matching license texts are included beside these files. The GUI loads the
bundles locally so the SCXML diagram works without network access.
